# ฟอร์มจัดการข้อมูลชำระบัญชี

## ติดตั้ง

จากโฟลเดอร์โครงการ รันคำสั่งนี้ในสภาพแวดล้อมที่ต้องการใช้งาน โดยตรวจว่า `.env` ชี้ไปยังฐานข้อมูลที่ถูกต้อง:

```sh
node scripts/migrateChamraManagement.js
```

คำสั่งสร้างตาราง `chamra_indicators`, `chamra_targets`, `chamra_meetings` และนำเข้าข้อมูลเดิมปี 2569 ได้แก่ ตัวชี้วัด 3 รายการ เป้าหมายถอนชื่อ/ติดตามคดีที่จับคู่ชื่อสถาบันใน `active_coop` ได้ และลิงก์รายงานการประชุม 4 ครั้ง ไม่แก้ตารางข้อมูลชำระบัญชีเดิม

ตรวจรายชื่อเป้าหมายหลังติดตั้ง เนื่องจากชื่อในฐานข้อมูลอาจไม่ตรงกับชื่อที่เคยเขียนในโค้ด ไฟล์ PDF เดิมไม่ได้รวมใน migration ต้องมีไฟล์ตามลิงก์เดิมบนเซิร์ฟเวอร์ หรือแนบไฟล์ใหม่ผ่านแบบฟอร์ม

ไม่รัน migration อัตโนมัติตอนเริ่มแอป หากยังไม่มีตาราง หน้า `/chamra` จะแสดงข้อมูลเดิม และหน้ารายการจัดการจะแจ้งว่ายังไม่ได้ติดตั้ง

## ใช้งาน

รายการเลือกปีแสดงปีล่าสุด 20 ปีย้อนหลัง และทุกปีเก่าที่พบข้อมูล พร้อมปุ่มปีก่อนหน้าและกลับปีปัจจุบัน เครื่องหมาย “มีข้อมูล” หมายถึงมีข้อมูลอย่างน้อยหนึ่งส่วนในระบบ เช่น ขั้นตอน ผลติดตาม ตัวชี้วัด เป้าหมาย หรือการประชุม ไม่จำเป็นต้องมีครบทุกส่วน

เข้าสู่ระบบด้วยสิทธิ์ `admin` หรือ `kjs` แล้วเปิด `/chamra` จะมีปุ่มจัดการ 3 ส่วน:

- `/chamra/manage/indicators`: ชื่อตัวชี้วัด ค่าเป้าหมาย ผลดำเนินการ หน่วยนับ หมายเหตุ
- `/chamra/manage/targets`: เลือกสถาบัน ประเภทเป้าหมาย วันครบกำหนด ผู้รับผิดชอบ หมายเหตุ
- `/chamra/manage/meetings`: ครั้งที่ วันที่ ชื่อการประชุม สรุปมติ และไฟล์ PDF ไม่เกิน 10 MB

แต่ละหน้ารองรับเพิ่ม แก้ไข ลบ และเลือกปีงบประมาณ พ.ศ. ค่าเริ่มต้นเป็นปีงบประมาณปัจจุบันตามเวลาไทย (เปลี่ยนปีวันที่ 1 ตุลาคม) เลือกปี 2569 เพื่อดูข้อมูลที่นำเข้า

ผลตัวชี้วัดเป็นค่าที่ผู้รับผิดชอบกรอก โดยระบบคำนวณร้อยละจากผล ÷ เป้าหมาย ไม่เชื่อมการคำนวณอัตโนมัติกับวันที่ขั้นตอนชำระบัญชี เป้าหมายเป็น 0 แสดงร้อยละเป็น —

การแก้ไขรายงานโดยไม่แนบไฟล์ใหม่จะใช้ไฟล์เดิม หากอัปโหลดไฟล์ใหม่หรือลบรายการ ระบบลบไฟล์ที่เคยอัปโหลดผ่านฟอร์มนี้หลังบันทึกฐานข้อมูลสำเร็จ โดยไม่ลบไฟล์ PDF เก่าที่อยู่ใน public

ต้องให้แอปเขียนโฟลเดอร์ `uploads/chamra-meetings` ได้ และสำรองทั้งฐานข้อมูลกับโฟลเดอร์นี้ รายงานที่แนบเปิดอ่านได้แบบสาธารณะเหมือนลิงก์รายงานเดิม

การเลือกปีครอบคลุมตัวชี้วัด เป้าหมาย รายงานประชุม ผลติดตามรายสถาบัน ตารางความเคลื่อนไหว และ PDF ของหน้าหลัก/หน้าประชุม โดยส่งปีที่เลือกผ่าน `?year=2570`

- ปีงบประมาณ 2570 = 1 ตุลาคม 2569–30 กันยายน 2570
- ปีเก่าสรุปขั้นตอนถึง 30 กันยายนของปีนั้น ปีปัจจุบันสรุปถึงวันนี้ตามเวลาไทย และปีอนาคตไม่มีความเคลื่อนไหวให้สรุป
- ขั้นตั้งต้นใช้สถานะก่อนวันที่ 1 ตุลาคม กิจกรรมในวันที่ 1 ตุลาคมนับเป็นความเคลื่อนไหวปีใหม่
- การถอนชื่อรายปีนับจากวันที่ขั้นที่ 9 โดยตรง ไม่ใช้วันที่ขั้นที่ 10
- ตารางรายเดือนแสดงทุกกิจกรรมในช่วงปี ไม่แสดงเฉพาะขั้นล่าสุดเพียงกิจกรรมเดียว
- หน้าประชุมและ PDF ใช้เป้าหมายรายสถาบันของปีที่เลือก สถาบันที่ไม่ถูกกำหนดเป้าหมายแสดงแยกต่างหาก
- เมื่อเปลี่ยนวันที่ประชุมในฟอร์ม ระบบเลือกปีงบประมาณตามวันที่ให้อัตโนมัติ เซิร์ฟเวอร์ตรวจว่าวันที่ประชุมและวันครบกำหนดเป้าหมายอยู่ในช่วงปีที่เลือก

หน้ากระบวนการ `/chamra/process` และรายละเอียดสถาบันยังใช้สำหรับดู/แก้ไขประวัติขั้นตอนทั้งหมด ส่วนรายงานตามปีใช้ข้อมูลขั้นตอนที่เกิดขึ้นไม่เกินวันรายงาน รายชื่อและสถานะสถาบันมาจากทะเบียนปัจจุบัน ระบบยังไม่มีประวัติการเปลี่ยนสถานะทะเบียนย้อนหลัง

## ตรวจสอบ

```sh
node --test test/chamraFiscalYear.test.js test/chamraManagement.test.js test/chamraSummary.test.js
npm test
```

ชุดทดสอบใช้ข้อมูลจำลอง ไม่เขียนฐานข้อมูลจริง ควรตรวจการบันทึกและอัปโหลดบนสภาพแวดล้อมทดสอบหลังติดตั้ง migration
