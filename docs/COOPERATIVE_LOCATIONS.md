# ระบบพิกัดสหกรณ์และกลุ่มเกษตรกร

ระบบนี้เก็บพิกัดสำนักงานแยกจากข้อมูลทรัพย์สิน และเชื่อมกับทะเบียน `active_coop` ด้วย `c_code`

## การใช้งาน

- ผู้ใช้ระดับ `admin` และ `pbt` เปิด `/cooperative-locations` เพื่อเพิ่มหรือแก้ไขข้อมูล
- วางพิกัด `latitude, longitude` หรือลิงก์ Google Maps แบบเต็มในแบบฟอร์ม ระบบจะช่วยแยกค่าพิกัด
- ลิงก์ย่อ `maps.app.goo.gl` ใช้เก็บเป็นแหล่งอ้างอิงได้ แต่ต้องเปิดลิงก์ก่อนเพื่อคัดลอก URL แบบเต็มหรือพิกัดตัวเลข
- เว็บไซต์ที่ไม่ระบุ scheme จะถูกเติม `https://` และระบบรับเฉพาะ `http`/`https`
- รายการต้องถูกทำเครื่องหมาย “ตรวจสอบว่าพิกัดถูกต้องแล้ว” จึงเปิดเผยบนหน้า Main ได้
- หน้า Main แสดงเฉพาะสถาบันที่ยังดำเนินการและมีสถานะตรวจสอบพร้อมเผยแพร่ ผู้ใช้กดจุดเพื่อเปิด Google Maps หรือเว็บไซต์ได้

## ฐานข้อมูล

Migration อยู่ที่ `sql/migrations/20260913_create_cooperative_locations.sql` และโมเดลมี `CREATE TABLE IF NOT EXISTS` สำหรับระบบที่อนุญาตให้บัญชีฐานข้อมูลสร้างตารางได้ หาก production จำกัดสิทธิ์ DDL ให้รัน migration ก่อน deploy

แผนที่ใช้ Leaflet และ OpenStreetMap ส่วนลิงก์ค้นหา/นำทางใช้ Google Maps URLs จึงไม่ต้องมี Google Maps API key
